# ARCHER2 Workload Research

This repository contains the full codebase, Jupyter notebooks, datasets, and interactive dashboard for my EPCC & Nuffield Research Placement project. The project investigates job loads and node-hour trends for the five most-used software applications on ARCHER2 from 2021–2026.

---

## 📁 Repository Structure

### `/notebooks/`
Jupyter notebooks for:
- yearly trends  
- seasonal trends  
- software usage  
- combined analysis  

### `/dashboard/`
Streamlit app for interactive data exploration:
- graphing scripts  
- download scripts  
- interactive visualisation tools  

### `/website/`
Flask web app for the research website:
- HTML templates  
- CSS files  
- Flask routes  
- contact form  

### `/data/`
Raw CSV files downloaded from ARCHER2 and the combined dataset used for analysis.
